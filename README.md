# Dayflow — Android

Dayflow is a mobile-first routine planner project being prepared for Android.

## Planned features

- Daily routines and task tracking
- Calendar with date and time selection
- Offline storage for routines
- Native Android notifications and scheduled reminders

## Build an APK

This project is intended to use a cloud build workflow with GitHub Actions and Gradle.

1. Upload the complete Android project files to this repository.
2. Include the `.github/workflows/` build workflow.
3. Open the **Actions** tab on GitHub.
4. Run the Android APK build workflow.
5. When the build succeeds, download the APK artifact from the completed workflow run.

## Important

The Android build and native notification behavior must be tested before this project can be considered ready to install and use. The README alone does not create an APK.
